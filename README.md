# Png-to-Svg-Generator
Alot of AI pay walled, and frankly, terrible ones out there. Here is one I have had for a while.

Uses, Pillow, NumPy, Shapely

# To Run
1. Install dependencies:

<code>python -m pip install -r requirements-tracing.txt</code>

2. Put PNG files in the picture folder.

3. Run the tracer:

<code>python trace_pngs.py</code>

Results are saved automatically in output/.

I used the Svg files, placed and sized the approriatey in tinkercad. The files were prepped by created only the desired colors, sorting them and exporting only those colors as a time, for example, if its a rainbow, there should be a picture of every color indiviudally for the rainbow. In tinkercad, orienting them correctly as well as extruding the surfaces to a proper height, I then placed those files in orca. Using the split tool, you can clean up the noise, by only copying the large full files, and deleting the microscopic ones.
